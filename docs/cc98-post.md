【分享】让吃灰的老 Kindle 重新刷 98 —— 一个自用的 Kindle 版 98 客户端

先交代背景:手头有个吃灰多年的 Paperwhite 3,想着拿来躺床上刷 98 应该很舒服,
结果发现根本打不开——新版 98 的前端会检测浏览器,老 Kindle 直接被判定"浏览器不受支持",
连登录页都看不到。查了下发现这是死路:Kindle 自带浏览器内核太老,越狱换浏览器又麻烦又折腾。

于是换了个思路:**不碰网页版,直接调 98 官方 API**。在电脑上跑一个本地小服务,
把帖子渲染成老浏览器能看的极简大字页面,Kindle 连同一个 Wi-Fi 打开一个网址就行了。
Kindle 端不用越狱、不用安装任何东西,电脑这边也是个零依赖的 Python 脚本(可选装一个 Pillow)。

目前已经做出来的功能:

· 导航:热门(十大热帖)/ 新帖 / 关注(收藏、关注的人、粉丝)/ 版面 / 我(我的主题、我的回复)
· 帖子:卡片式排版,楼主标签、楼层号、点赞/踩数、楼主头像,点头像进个人主页
· 回帖:支持回复主题和匿名回复,失败原因(发帖太快、帖子锁定等)都会明确提示
· 图片:帖子图片和头像自动加载,98 现在的 WebP 图片会自动转成 JPEG 发给 Kindle
· 表情:98 的 em/ac/tb/ms 表情包全部渲染成图片;Unicode emoji(😭这种)用系统字体本地
  渲染成小图,不联网
· 专门为墨水屏调过:无 JS、无动画、大字号、黑白高对比,翻页靠大按钮

使用方法三步:

1. 电脑(需在校园网或 RVPN)上装好 Python,跑起本项目
2. 在配置文件里填上自己的 98 账号密码(只存在本地,用于换登录令牌)
3. Kindle 连上同一个 Wi-Fi,浏览器打开程序启动时打印的地址(形如 http://192.168.x.x:8000/k/xxxxxx/),
   存个书签,以后一点即进

几个小提示:

· 校园 Wi-Fi 如果开了设备隔离(互相 ping 不通),可以开电脑的移动热点,让 Kindle 连热点,
  用 192.168.137.1 的地址访问
· 电脑睡眠/程序关掉后 Kindle 就打不开了,所以适合电脑常开着的同学
· 程序自带了访问口令保护,同网段的其他人打不开,不用担心被蹭
· 密码只保存在你自己的电脑上,程序不做签到、不改账号设置,只浏览+回帖

开源地址(欢迎试用、提 issue、提 PR):
https://github.com/XhWLIGHt/cc98-kindle

声明:纯自用工具顺手开源,非官方项目;使用时请遵守 98 的论坛章程,别拿它爬数据或批量发帖,
也千万别把自己的账号配置分享给别人。
